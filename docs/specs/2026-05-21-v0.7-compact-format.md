# v0.7.0 — 출력 포맷 압축 (2-line row + 별점)

**날짜**: 2026-05-21
**입력**: 사용자 요청 — Top 10 row를 2-line compact 형식으로. 보조 메타(백킹/펀딩/리서치/시간/마감/태그) 모두 제거, 별점 5단계 추천도 추가.

## 변경 사항

### 1. Row 포맷 (출력)

- **이전 (v0.6)**: 6-7 line / row.
  ```
  1. <프로젝트명> [비용없음][딸각] · <활동유형> · 시간=<...>
     백킹: <VC1 · VC2> · 펀딩 $<X.XM>
     리서치: <N>건
     할 일: ...
     마감: <YYYY-MM-DD>
     출처: <URL>
  ```
- **변경**: 2 line / row.
  ```
  (링크 (<URL>)) <프로젝트명>(<티커>) - <할 일 한 줄>
  추천도: ★★★★★
  ```

### 2. 추천도 (★ 5단계)

ROI 가중 요소를 별점 1-5로 압축. LLM이 다음 룰로 매핑:

- **★★★★★** (5): 강한 백커(a16z급) + 자본=없음 + 시간 짧음 + 명시 마감 임박 + 리서치 ≥5건. 4-5개 양수 시그널.
- **★★★★☆** (4): 양수 시그널 3개.
- **★★★☆☆** (3): 양수 시그널 2개.
- **★★☆☆☆** (2): 양수 시그널 1개.
- **★☆☆☆☆** (1): hard filter 통과는 했지만 모든 시그널 약함.

### 3. 정렬 기준

- **이전 (v0.6)**: 마감 임박순 (primary) + ROI 가중 tie-breaker.
- **변경**: **추천도 별점 내림차순** (★★★★★ → ★☆☆☆☆). 같은 별점은 마감 임박순 tie-breaker.

### 4. 카테고리 태그 제거

- v0.5에서 도입한 `[비용없음]` `[딸각]` 태그는 출력에서 제거. 사용자 v0.7 요청에 자리 없음.
- 분류 로직 자체는 제거 (헤더 row에 들어갈 곳 없음). 단 `[비용없음]` 즉 자본=없음 hard filter는 **유지** (v0.5부터 동일).
- `[딸각]` 판정은 ROI 가중치 산정 시 양수 시그널 1개로 흡수 (one-time + ≤30분).

### 5. 보조 필드 제거 (백킹/펀딩/리서치/시간/마감)

출력 row에서 모두 제거. 단 다음 용도로는 **계속 추출**:
- 별점 산정 input (백커·펀딩·리서치 → 별점에 흡수).
- Skipped 섹션에 fallback context.
- pin routine snapshot 박제 시 메타로 활용 가능.

### 6. 헤더 변경

- **이전**: `🪂 오늘의 에어드랍 Top 10 — 마감 임박순 (YYYY-MM-DD)`
- **변경**: `🪂 오늘의 에어드랍 Top 10 — 추천도순 (YYYY-MM-DD)`

### 7. 티커 처리

- 프로젝트 페이지에 티커 명시되면 `프로젝트명(TICKER)`. 미정이면 `프로젝트명(티커 미정)`.

### 8. 핀 snapshot 정규화 룰 (airdrop_pin.md §6)

- 핀에 박제되는 `snapshot_md`도 같은 2-line 포맷 따름:
  ```
  (링크 (<URL>)) <프로젝트명>(<티커>) - <할 일>
  ```
  추천도는 핀에 박지 않음 (시간 지나면 stale).

## 변경 없음 (v0.7에서도 그대로)

- 자본=없음 hard exclude.
- daily 1회 cron + Telegram 채널 broadcast (Task 7 인프라).
- pin 명령은 Claude CLI 자연어 + `cache/latest-digest.md` 참조.
- Skipped/excluded 섹션 (디버깅용).

## v0.7에서 다루지 않는 것

- 별점 산정 일관성 자동 검증 — LLM judgment 영역, 첫 broadcast 사용자 확인 후 prompt 튜닝.
