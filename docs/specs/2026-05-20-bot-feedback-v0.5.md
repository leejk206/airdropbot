# v0.5.0 — 태혁 피드백 1차 반영

**날짜**: 2026-05-20
**입력**: 태혁(BAY 멤버) 카톡 피드백 — routine 출력 개선 위주.
**범위**: `prompts/airdrop_digest.md`, `README.md`. 봇 디스패치 인프라는 별도 sprint (TBD).

## 변경 사항

### 1. 정렬: 마감 임박순 (primary)

- **이전**: ROI 가중치 점수순.
- **변경**: primary sort = `expires_at` (마감일) ascending. 미정/TBA는 가장 뒤. tie-breaker = 기존 ROI 가중.
- **이유**: 태혁 "남은 기간 순서로 리스팅"(5:21).

### 2. 카테고리 태그 (row 인라인, 단일 섹션)

- **분류**: `[비용없음]` (자본=없음, 현재 hard filter 통과 항목 = 항상 부착) + `[딸각]` (시간=one-time AND 단발 + 추정 시간 ≤30분 또는 단순 클릭형).
- **출력**: row 헤더에 태그 인라인. 섹션 분리 안 함 (단일 Top N).
- **이유**: 태혁 "비용 없는 것 / 딸각 인 것"(5:20-21). overlap은 "row에 태그 붙이고 섹션은 하나"(사용자 결정).

### 3. 백킹/펀딩 별도 필드 + 항상 표시

- **이전**: "왜 ROI 상위" 한 줄 안에 섞여 있음.
- **변경**: `백킹: <VC 이름들> · 펀딩 $<금액>` 별도 필드. 정보 없으면 `백킹: 정보 없음`.
- **이유**: 태혁 "투자 얼마나 받은지(VC가 누구인지)"(5:22).

### 4. 리서치 카운트 (best-effort)

- **변경**: sources.yaml 6개 URL fetch 결과에 리서치 보고서 카운트(예: cryptorank "Research: N건")가 명시되면 `리서치: <N>건` 필드 추가. 없으면 생략. **추가 URL fetch 없음**.
- **이유**: 태혁 "리서치도 마케팅 fee이기 때문에 많을수록 마케팅에 돈 많이 태우는구나"(5:11-12). 사용자 결정 = v1 best-effort.

### 5. "왜 ROI 상위" 필드 제거

- **이전**: 한 줄 ROI 근거 텍스트.
- **변경**: 제거. 정렬이 ROI 순서가 아니라 마감순이라 근거 텍스트 의미 약화. 백킹/펀딩/리서치/카테고리 태그가 이미 ROI 근거를 분산해서 보여줌.
- **이유**: 태혁 "포맷/디자인/말투 보기좋게 바꾸자"(5:10) — 군더더기 제거.

### 6. 헤더 문구 변경

- **이전**: `🪂 오늘의 ROI Top 10 (YYYY-MM-DD)`
- **변경**: `🪂 오늘의 에어드랍 Top 10 — 마감 임박순 (YYYY-MM-DD)`
- **이유**: 정렬 변경 반영.

## 변경 없음 (피드백에 있었지만 default 유지)

- **자본=없음 hard exclude**: v1은 사용자 프로필 "자본 0" 유지. 향후 사용자별 toggle 추가 검토 가능.
- **자동 스캠/해킹 필터**: 태혁 본인 5:24 철회("직접 리서치해서 아니다 싶은건 필터링"). 본 routine은 자동 필터 없음. 사용자 수동 제외.
- **하루 추천 개수**: top 10 유지 (태혁 "상관없음").

## v0.5에서 안 다루는 것 (TBD)
